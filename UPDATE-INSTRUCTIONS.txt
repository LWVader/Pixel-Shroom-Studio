To create one supplier DRAFT (not production):
1. Copy tools/gelato-test-recipient.example.json to a private file OUTSIDE the project and replace every REPLACE value with your own valid US address/email.
2. Have an HTTPS URL for a print-ready file that Gelato can download. Use a dedicated print file; do not use the watermarked preview. A short-lived private signed URL is suitable if valid long enough for Gelato processing.
3. Run from the project root:
.\tools\test-gelato-draft.ps1 -PrintFileUrl 'YOUR_HTTPS_PRINT_URL' -RecipientJsonFile 'C:\private\gelato-recipient.json'

The script securely prompts for the API key locally (not stored), obtains a USD quote/shipping method, and creates exactly one 16x16 thick-canvas draft. It never converts to production. Optional -ProductUid selects one of your other product UIDs; match the file composition to that product.
