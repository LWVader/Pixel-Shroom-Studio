ADMIN WORKFLOW
Images: native computer file browsing, compact full-width tier settings, a six-card upload grid and local preview thumbnails. The LWVader default, fixed roll pricing, six-tier requirement, signing and private source workflow are preserved.

Gelato: Browse site artwork opens a thumbnail picker. Choose from computer opens the native file chooser. Select the artwork/tier, then drag, resize, zoom or use sliders to position the image. Arrow keys and +/- work on the focused positioning canvas. Only 16x16 unframed and 16x20 portrait framed formats are loaded, mapped to the promised tiers.

Preview canvas opens angled, front and wall views, styled after the supplied recording. These are studio mockups, not official Gelato photography. Exact finish and product template still come from the chosen Product UID.

Save image position generates the actual private positioned print PNG and a protected 720px preview; it automatically fills the print path, preview URL, dimensions and print-file hash. Source identity and position metadata are retained. The source tier file and issued digital editions remain unchanged. Editing the position or print-area settings requires saving again.

Product UID, tax code and template settings are reused when a compatible saved tier mapping exists. Unknown values are not guessed. Enter exact product-specific bleed/wrap if not already configured. Roll prices and existing later-print prices are unchanged.

Publish product runs the technical check and asks for Confirm/Cancel. The server re-reads the source and print files, checks hashes and verifies actual cropped source resolution. Low-resolution crops cannot pass by enlarging the export. No image or order is sent to Gelato while preparing, previewing or saving a position.
