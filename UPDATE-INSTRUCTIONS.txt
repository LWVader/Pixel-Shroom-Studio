GELATO ADMIN TAB UPDATE

1. Extract this ZIP into your project root, replacing the included files.
2. From PowerShell in that project root, run:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\cleanup-retired-products.ps1
   This removes only the 14 retired source/test/guide files listed in DELETED-FILES.txt.
3. Run npm.cmd ci
4. Run npm.cmd run build
5. Deploy using your normal Cloudflare deployment command (for example npx.cmd wrangler deploy).
6. Open Admin, then Gelato. Hard-refresh if the old admin page was cached.

No new database migration, secret update or Edge Function deployment is needed.
Two historical migration files have comment-only edits; their SQL statements and migration IDs are unchanged. Do not rerun them.
Existing stored products, artwork, paid orders, accounts and payment paths are preserved.
The old physical-product form was removed from Images and moved to Admin > Gelato.
The Gelato storefront and print checkout remain the physical-product path.
