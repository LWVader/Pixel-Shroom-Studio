Canvas & print setup

Connect an artwork to a Gelato product. Your dedicated print file stays private until an order is sent for production.

1. Choose artwork & tier

Use Refresh products & orders to load your artwork list, or enter an artwork ID below.

Artwork ID / standalone product

Leave the tier empty for a standalone physical product. To link a Vault edition, select its artwork and tier.

2. Connect the Gelato product

Find the exact size and finish in the Gelato catalog. Copy its Product UID from below the description. Tier suggestions still need a matching UID.

Choose a tier for suggested size, finish and later-print price.

Listing details & tax

A protected preview is used on your site. Select the correct Stripe tax code for this product; it is required to save.

3. Upload & check the print file

Upload the composition for this exact product, confirm its template settings, then run the check. Nothing is sent to Gelato during this step.

Technical settings — confirm against the Gelato template

Full file = finished size + bleed + any additional wrap on both sides. Enter 0 for margins already included in the supplied full-area size. Gelato’s general PDF guidance uses 4 mm bleed and at least 4 mm safe margin; the exact product template takes precedence.

The dashed guide marks the requested safe zone. Inspect the exported file in your design application as well.

Review before approval

Select an artwork file and enter the product template requirements.

Gelato PDF requirements · Gelato apparel guidance

Safe check is a technical check plus your review, not a guarantee or Gelato production approval. It does not detect all halos, missing fonts, incorrect product UIDs, interpolation or out-of-gamut colors.

4. Save & publish

Unchecked Publish saves a hidden draft. Publishing still follows your server’s checkout settings.
